# VSRT-LANG

**VSRT-LANG** — система обучения иностранным языкам на основе метода интервального повторения с использованием карточек.

Пользователь создаёт учебные сессии и формирует в них набор изучаемых слов. Система автоматически дополняет каждое слово дополнительной информацией: переводом, значениями, синонимами, антонимами, контекстами использования и другими связанными данными.

## Архитектура

Проект построен на микросервисной архитектуре и состоит из следующих компонентов:

* **manager** — основной backend и публичный API
* **translator** — сервис получения лингвистической информации
* **web-ui** — веб-интерфейс приложения
* **libretranslate** — сервис машинного перевода
* **database** — PostgreSQL

### Manager

`Go-Manager` — основной backend-сервис, предоставляющий внешний API приложения.

Основные задачи:

* авторизация и управление пользователями;
* обработка запросов от клиента;
* оркестрация взаимодействия между сервисами;
* работа с учебными сессиями и карточками.

### Translator

`Translator` — сервис для получения и обработки информации о словах.

Сервис предоставляет данные, связанные со словом, включая:

* перевод;
* значения;
* синонимы;
* антонимы;
* контексты использования;
* другие лингвистические данные.

### Web UI

`web-ui` — React-приложение, предоставляющее пользовательский веб-интерфейс системы.

Через интерфейс пользователь может взаимодействовать с учебными сессиями и карточками.

### LibreTranslate

`libretranslate` — внешний сервис машинного перевода, используемый `Translator` для получения переводов.

### Database

В качестве базы данных используется **PostgreSQL**.

## Запуск

### Требования

Для запуска проекта необходимо установить:

* Docker
* Docker Compose

### Переменные окружения

Перед запуском необходимо создать файл `.env`.

Описание требуемых переменных окружения находится в документации соответствующих сервисов:

* [`Go-Manager/docs/configuration.md`](Go-Manager/docs/configuration.md)
* [`Translator/README.md`](Translator/README.md)

### Запуск через Docker Compose

Сначала необходимо собрать контейнеры:

```bash
docker-compose build
```

После сборки запустить сервисы:

```bash
docker-compose up
```

## Возможная проблема при запуске

При первом запуске может возникнуть ситуация, при которой `libretranslate` не успевает завершить инициализацию до запуска `translator`.

В результате `translator` может завершиться с ошибкой.

Если это произошло, необходимо перезапустить сервис `translator`:

```bash
docker-compose restart translator
```

После успешной инициализации `libretranslate` сервис `translator` должен запуститься корректно.
